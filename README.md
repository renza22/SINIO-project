# SINIO-project — Hotel Management / Sistem Manajemen Hotel

Proyek aplikasi manajemen hotel berbasis Java + web, untuk mengelola reservasi, kamar, tamu, dan pembayaran.

## 📁 Struktur Proyek  
- `src/` — kode sumber backend / frontend
- `dump-defaultdb-202510312015.sql` — skrip SQL untuk database default  
- `pom.xml` & `mvnw` — konfigurasi build dengan Maven (untuk Java / Spring Boot)  
- `.gitignore`, `.gitattributes` — konfigurasi git

## ✅ Fitur Utama  
- CRUD kamar (tambah, ubah, hapus kamar)  
- Manajemen reservasi — booking kamar, check-in / check-out  
- Manajemen tamu (data tamu, histori kunjungan)  
- Sistem pembayaran / invoice  
- Autentikasi & manajemen pengguna (user/role)  
- Database MySQL (skrip SQL tersedia)
